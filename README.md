# flovatar-brand

The Flovatar brand style guide v2: a single handover that lets any human or AI agent create in the Flovatar style. Published at **https://brand.flovatar.com** (a static site in object storage behind Cloudflare).

| Path | What |
|---|---|
| `BRAND.md` | **The master handover.** Self-contained, generated from `guide/`. Paste it into an agent. |
| `guide/NN-*.md` | Source sections (edit these). |
| `tokens/` | `design-tokens.json` (W3C-style), `tokens.css`, `contrast.md`, Ultimate rarity `ultimate.css` + glitter SVGs (blue-noise layers `ultimate-glitter-509/613/757.svg`, `ultimate-glitter-pattern.svg`), all generated by `tools/build-tokens.py`. |
| `web/` | Static site sources: `style.css`, `app.js`, `robots.txt`, `404.html`, `og.jpg`, favicons and `assets/` (optimised logos SVG/PNG, icons, sample renders, `anatomy/` construction figures rendered from public on-chain template SVGs, story/asteroid art, layout references, superseded v1.0 PDF). |
| `tools/` | `build.py` (guide + web → `dist/`), `template.html`, `hero.html`, `build-tokens.py`, `prepare-assets.py` (re-creates `web/assets/` from the original files; source locations in a local, gitignored `tools/assets.local.json`, see `tools/assets.example.json`), `make-og.py`. |
| `scripts/publish.sh` | Syncs `dist/` to an S3-compatible bucket with per-type Content-Type and Cache-Control. Target from env vars or a gitignored `scripts/publish.local.env` (`BUCKET`, `S3_ENDPOINT`, optional `AWS_PROFILE`). |
| `dist/` | Build output (**gitignored**: it contains licensed webfonts). |
| `dist-private/fonts/` | Licensed `.woff2` webfonts (**gitignored**; kept by the Flovatar team, published to the site only). |

## Build & publish

```bash
python3 -m venv .venv && .venv/bin/pip install markdown pillow
# put the licensed webfonts in dist-private/fonts/ (korolev-condensed-bold.woff2, korolev-compressed-bold.woff2,
#   staatliches-latin.woff2, staatliches-latin-ext.woff2, roboto-condensed-latin.woff2, roboto-condensed-latin-ext.woff2;
#   the latin-ext files carry the Đ of ĐUST); without them the site falls back to system fonts
.venv/bin/python tools/build-tokens.py   # only if colours/type changed
.venv/bin/python tools/build.py          # → BRAND.md + dist/
python3 -m http.server -d dist 8000      # local preview: http://127.0.0.1:8000/index.html
BUCKET=… S3_ENDPOINT=… scripts/publish.sh  # or put them in scripts/publish.local.env (gitignored)
```

The bucket has no directory-index handling, so every internal link points to an explicit file (`/voice/index.html`). A Cloudflare URL-rewrite rule maps paths ending in `/` to `index.html` for pretty URLs. CSS, JS and fonts are content-hashed under `/static/` (cached for a year); HTML/MD/TXT/JSON are cached for 5 minutes, media for 1 day.

## Rules for editors

- Keep facts sourced and mark interpretations **[inferred]**. Credit art to "the Flovatar team" and never name individual artists. Keep internal, legal and financial history out.
- **This repo is public:** never commit font files (`.otf/.ttf/.woff/.woff2`), design sources (`.ai/.psd/.indd`), secrets, personal data, or internal details (storage locations, machine paths, server names, internal channels or documents, private business figures, unannounced plans). `.gitignore` blocks the common files. Run assets through `tools/prepare-assets.py`, which strips SVG comments, PDF metadata and image metadata.
- Bump `VERSION` in `tools/build.py` (the guide pulls it in via `{{VERSION}}`). The guide states rules only: no changelog, no open-questions section, no decision/approval notes. History lives in git.
